# Superstore-
Superstore powerBi project
This project is made using superstore sample data using PowerBi Version: 2.141.1558.0 64-bit (March, 2025)
in page 1 it has an bar chart which Total Sales by Sub-category 
in page 2 i have used cards to Show total sales ,no of customer , no of orders,total profit, shipping mode used most in a particular city , i have added slicer so that user can filter data and get information about 
particular city.
in page 3 it has 2 bar charts for Total profit in each region and Total profit from each Sub category.
The data used is available in kaggle.
